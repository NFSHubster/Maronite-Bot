# ✝️ Maronite Bot (r/Maronite Official)

The official community and liturgical assistant for the **Maronite Christianity** Discord server. This bot is designed to serve the Maronite Christian community by providing spiritual resources, automated moderation, and daily liturgical updates.

---

## ✨ Key Features

*   **🙏 Daily Prayers:** Automatically posts Maronite liturgical prayers and "Saint of the Day" updates.
*   **🛡️ Advanced Moderation:** Custom tools to keep the community safe and respectful.
*   **📖 Scripture Search:** Instant access to Bible verses and Maronite lectionary readings.
*   **🎨 Custom Embeds:** Allows authorized users to send beautifully styled announcements directly within Discord.
*   **⛪ Community Hub:** Links to r/Maronite resources and regional parish information.

## 🛠️ Installation & Setup

1. **Clone the repo:**
   ```bash
   git clone https://github.com
   ```

2. **Install Dependencies:**
   ```bash
   npm install  # for Node.js
   # OR
   pip install -r requirements.txt # for Python
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your bot token:
   ```env
   TOKEN=your_discord_bot_token_here
   ```

4. **Run the Bot:**
   ```bash
   node index.js # or python main.py
   ```
